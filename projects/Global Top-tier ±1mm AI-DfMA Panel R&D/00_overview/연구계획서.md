## 1. 과제 개요

### 1.1 과제명

**Global Top-tier ±1mm 초정밀도의 AI 및 DfMA 기반 알루미늄 이중휨 패널 생산 시스템 개발**

### 1.2 개발 배경 및 필요성

알루미늄 이중휨(Double-curved) 패널은 건축·항공·모빌리티 분야의 고부가가치 외장재로 수요가 증가하고 있다. 그러나 기존 수작업 중심의 제작 방식은 최종 정밀도가 ±3~5mm 수준에 머물러 글로벌 Top-tier 프로젝트 납품 기준(±1mm)을 충족하지 못하고 있다.

이를 해결하기 위해서는 설계 자동 전개, 열성형, 3D 스캔 기반 보정, 정밀 트리밍의 전공정을 **Digital Thread**로 통합 연결하고, AI가 각 공정의 오차를 실시간으로 학습·보정하는 자동화 생산 시스템이 필요하다.

### 1.3 최종 목표

설계 → 전개 → 성형 → 검측 → 보정 → 트리밍 전공정을 Digital Thread로 통합 자동화하여, **알루미늄 이중휨 패널 최종 제작 정밀도 ±1mm**를 달성한다.

## 2. 연구 내용 및 3대 개발축

### 2.1 개발축 구조

```
[설계 입력 (Rhino/GH)]
         |
         v
[① AI 기반 자동 전개 SW]   <- ExactFlat API + FEA 보정 매핑
         |
         v
[② 인덕션 히팅 다점 프레스]  <- 핀베드 + 재결정 온도 가열 + 저압 성형
         |
         v
[③ 3D 스캔 + 로봇 레이저 트리밍] <- 오차맵 -> 보정 -> 정밀 절단
         |
         v
     [±1mm 패널 완성]
```

---

### 2.2 개발축 ① — AI 기반 자동 전개 소프트웨어 (WBS-300)

**목표:** 이중휨 곡면을 평판으로 자동 전개하고, FEA 기반 스프링백·열변형 보정을 적용하여 성형 및 절단 파라미터를 즉시 산출한다.

| 세부 항목 | 내용 |
|-----------|------|
| 상용 모듈 | Rhino 플러그인 + ExactFlat API (곡면 전개/패턴 생성) |
| 추가 개발 | FEA 결과(열변형/스프링백) 보정 매핑 모듈 |
| 추가 개발 | 전개 결과 -> 핀좌표/로봇 툴패스 자동 변환기 |
| 추가 개발 | 배치 실행·버전관리·이력추적 (Digital Thread) |
| 해석 연동 | ANSYS API (1순위, 열-기계 연성), SAP2000 API (2순위, 구조 검토) |

**자동화 파이프라인:**

```
Rhino/GH 입력 -> ExactFlat 전개 -> 해석모델 생성(ANSYS)
-> 해석 실행 -> 결과 파싱(변형/응력/스프링백)
-> Rhino 역피드백 -> 성형/절단 파라미터 자동 업데이트
```

---

### 2.3 개발축 ② — 인덕션 히팅 가변형 다점 프레스 장비 (WBS-400/500)

**목표:** 알루미늄 이중휨 형상 성형에 최적화된 가변형 다점 프레스 장비를 개발한다.

| 세부 항목 | 내용 |
|-----------|------|
| 장비 규모 | 1m x 1m |
| 성형 방식 | 리니어 액추에이터 + 핀베드 모듈 |
| 성형면 | 메쉬망 + 고내열 실리콘 패드 |
| 가열 방식 | 인덕션 히팅 (재결정 온도 가열 + 저압 성형) |
| 제어 | PLC 기반 다축 제어, 안전 인터록 회로 |

---

### 2.4 개발축 ③ — 3D 스캔 피드백 + 로봇 레이저 트리밍 (WBS-600/700)

**목표:** 성형 후 실측 데이터를 AI 보정 루프에 연결하고, 최종 외곽 정밀도를 로봇 레이저로 확정한다.

| 세부 항목 | 내용 |
|-----------|------|
| 스캔 | 실시간 3D 스캔 오차 분석 및 오차맵 생성 |
| AI 보정 | 스캔 데이터 기반 성형 파라미터 자동 보정 (스프링백/열변형) |
| 트리밍 | 최적 외곽 라인 생성 -> 다관절 로봇 레이저 절단 |
| 검증 | 반복 제작 재현성 측정, Cp/Cpk 공정능력 분석 |

## 5. 세종대학교 협력 연구 계획

### 5.1 세종대 워크스코프

1. 알루미늄 시트 물성 및 열-기계 거동 모델링 (온도 구간 포함)
2. 성형 조건별 FEA 시뮬레이션 (스프링백·잔류응력·형상오차)
3. 3D 스캔 실측 대비 해석모델 보정
4. 공정 파라미터 민감도 분석 및 최적 영역 제시 (온도/압력/핀 분해능/트리밍 순서)
5. 구조·사용성 검토 리포트 및 설계 권고안

### 5.2 세종대 KPI

| KPI | 지표 | 기준값 |
|-----|------|--------|
| KPI-S1 | 해석-실측 오차(MAE) | 중간 <=1.5mm / 최종 <=1.0mm |
| KPI-S2 | 변형 예측 상관계수 | R² >= 0.85 |
| KPI-S3 | 보정 알고리즘 적용 후 오차 개선율 | 30% 이상 |
| KPI-S4 | 공정 파라미터 가이드라인 | 최적 영역 도출 1세트 |
| KPI-S5 | 기술문서·자문보고서 정시 제출율 | 100% |

### 5.3 데이터 인터페이스 규약 (W04 이전 확정)

- 데이터 전달 포맷: JSON / CSV (버전 규약 포함)
- 공유 주기: 주 1회 정기 전달 + 마일스톤 시 전체 패키지
- 공유 채널: 공동 저장소 (버전관리 적용)
