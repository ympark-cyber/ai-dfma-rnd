## 세종대 워크스코프 및 KPI
### 워크스코프
1. 알루미늄 시트 물성 및 열-기계 거동 모델링
2. 성형 조건별 FEA (스프링백/잔류응력/형상오차)
3. 3D 스캔 실측 대비 해석모델 보정
4. 공정 파라미터 민감도 분석 및 최적영역 제시
5. 구조/사용성 검토 리포트 및 기술자문

### KPI
- KPI-S1: 해석-실측 MAE ≤ 1.5mm(중간), ≤ 1.0mm(최종)
- KPI-S2: 변형 예측 R² ≥ 0.85
- KPI-S3: 보정 적용 후 오차 30% 이상 개선
- KPI-S4: 공정 파라미터 가이드라인 1세트 제출
- KPI-S5: 자문/기술문서 정시 제출율 100%

## ExactFlat + 구조해석 자동화 계획
### 도입 방향
- ExactFlat 상용 전개 + 추가 개발 모듈 결합
- 추가 개발: FEA 보정 매핑, 핀좌표/로봇 툴패스 변환, 배치 실행/이력 추적

### 해석 연동 우선순위
1. ANSYS API 우선(열-기계 연성 및 자동화 유연성)
2. SAP2000 API 병행(구조 안정성 검토 축)

### 자동화 파이프라인
Rhino/GH 입력 → ExactFlat 전개 → 해석모델 생성 → 해석 실행 → 결과 파싱(변형/응력/스프링백) → Rhino 피드백 → 성형/절단 파라미터 업데이트
