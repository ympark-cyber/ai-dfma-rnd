## B) 세종대 요청 워크스코프 + KPI + 실험/산출물 일정

### 세종대 워크스코프(요청안)
1) 재료 물성/열-기계 거동 모델링(알루미늄 시트, 온도구간 포함)
2) 성형 조건별 FEA 시뮬레이션(스프링백/잔류응력/형상오차)
3) 실측(3D 스캔) 대비 해석모델 보정
4) 공정 파라미터 민감도 분석(온도/압력/핀분해능/트리밍 순서)
5) 구조/사용성 검토 리포트 및 설계 권고안

### KPI (세종대 담당)
- KPI-S1: 해석-실측 오차(MAE) ≤ 1.5mm (중간), ≤1.0mm (최종)
- KPI-S2: 변형 예측 상관계수 R² ≥ 0.85
- KPI-S3: 보정 알고리즘 적용 후 오차 30% 이상 개선
- KPI-S4: 공정 파라미터 가이드라인 1세트(최적영역 도출)
- KPI-S5: 기술문서/자문보고서 정시 제출율 100%

### 세종대 실험·산출물 일정
- W4: 실험계획서(DoE), 측정기준서
- W6: 물성 DB v1, FEA 기준모델 v1
- W8: 단일곡률 검증 리포트
- W11: 이중곡률 초기 검증 리포트
- W14: 해석-스캔 비교리포트 v1
- W16: 보정모델 파라미터셋 v1
- W19: 통합검증 리포트 v2
- W21: 최종 성능검증 리포트(±1mm 근거)
- W24: 최종 기술자문서/데이터 패키지

## C) ExactFlat 도입 + ANSYS/SAP2000 API 연동 계획

### C-1. ExactFlat 활용/추가개발
- 상용 모듈: 곡면 전개/패턴 생성
- 추가개발:
  - FEA 결과(열/스프링백) 보정 매핑 모듈
  - 전개결과→핀좌표/로봇툴패스 변환기
  - 배치 실행/버전관리/이력추적(Digital Thread)

### C-2. 구조해석 연동 전략
- 1순위: ANSYS API 연동 (열-기계 연성/자동화 유연성)
- 2순위: SAP2000 API 병행 (구조 안정성·프레임 검토 축)

### C-3. 자동화 파이프라인
Rhino/Grasshopper 입력
→ ExactFlat 전개
→ 해석모델 생성(ANSYS/SAP2000)
→ 해석 실행
→ 결과 파싱(변형/응력/스프링백)
→ Rhino 역피드백
→ 성형/절단 파라미터 자동 업데이트

### C-4. 단계별 납품물
- M1 (W8): 단방향 자동해석(수동 승인형)
- M2 (W14): 양방향 피드백(반자동)
- M3 (W18): 배치 최적화 루프(자동)
- M4 (W21): 운영형 안정화(SOP 포함)
