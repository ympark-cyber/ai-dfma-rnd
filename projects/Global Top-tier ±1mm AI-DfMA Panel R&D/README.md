# Global Top-tier ±1mm AI·DfMA Panel R&D

로컬 Markdown 운영 루트입니다.

## 폴더 구조
- `00_overview/` 과제 요약/핵심정의
- `01_plan/` 실행계획, 마일스톤
- `02_reports/weekly/` 주간 보고
- `02_reports/monthly/` 월간 점검
- `03_risks/` 리스크 레지스터
- `04_evidence/` 증빙 목록/링크
- `05_meetings/` 회의록
- `06_exports/` 외부 공유용 PDF/문서
- `07_data/` KPI/실험 데이터 CSV

## 운영 규칙 (간단)
1. 파일명은 `YYYY-MM-DD_제목.md`
2. 보고서는 주간/월간 폴더에 분리 저장
3. 모든 변경은 git commit으로 이력 남김
4. 리스크는 월 1회 재평가
