# 02. 평가·점검 대응 1페이지 요약

## 과제 한줄 요약
AI·DfMA 기반 Digital Thread로 알루미늄 이중휨 패널 제작 전공정을 자동화해 기존 ±3~5mm를 ±1mm로 고도화하는 초정밀 생산 시스템 개발.

## 3대 개발축
1) AI 기반 자동 전개 소프트웨어
- Rhino 플러그인 + ExactFlat API
- 세종대 FEA(열변형/스프링백) 학습 반영
- 핀 위치/로봇 툴패스 즉시 변환

2) 인덕션 히팅 기반 가변형 다점 프레스(1m x 1m)
- 리니어 액추에이터 + 핀베드 모듈
- 메쉬망 + 고내열 실리콘 패드 성형면
- 재결정 온도 가열 + 저압 성형

3) 3D 스캔 피드백 + 로봇 레이저 트리밍
- 실시간 스캔 오차 분석
- 최적 외곽 라인 생성
- 다관절 로봇 레이저 절단으로 최종 정밀도 확정

## 정량 KPI
- 제작 정밀도: ±1mm 달성
- 제작비: 30% 절감 목표
- 재작업률/폐기율: 유의미한 감소
- 공정: 전개→성형→검측→보정→절단 폐루프 자동화

## 주요 산출물
- 특허(출원), 논문(SCI/비SCI), 사용자 매뉴얼
- 인증 준비(NEP/CE/ISO)
- 통합 검증 리포트(반복 재현성 포함)

## 리스크 대응 핵심
- 장비 튜닝 지연: 단계별 시험계획 + 대체 파라미터 세트
- 데이터 품질: 스캔/FEA 데이터 표준화 및 버전관리
- 정밀도 미달: 보정 루프 기간 별도 확보(스캔, 컷팅)
